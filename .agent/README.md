# Agent Configuration

This directory contains agent definitions for the Airbnb Clone project.

## Structure

```
.agent/
├── README.md            ← this file
└── (agent configs)      ← to be added in Phase 7
```

## Agents (planned)

- **architecture-agent** — answers questions about the project structure
- **frontend-agent** — handles Next.js/React feature work
- **backend-agent** — handles Express API work
- **accessibility-agent** — audits and fixes a11y issues
- **visual-agent** — handles CSS and visual fidelity work

## Usage

Agent configuration files follow the Antigravity AGY SDK format.
See `docs/ai-workflow.md` for the full AI workflow documentation.
